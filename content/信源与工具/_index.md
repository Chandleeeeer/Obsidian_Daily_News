# 信源与工具 · 索引

用于收集「政策 + 行业信息」的工具、RSS 源与官方网站清单。

## 子笔记

- [[政策监控工具]]：国内 + 国际 / 全球政策监控
- [[每日日报聚合工具]]：AI 每日日报、聚合与 Obsidian 集成
- [[RSS 基础设施]]：RSSHub、阅读器与自动化框架
- [[建议订阅信源清单]]：官方政策源与行业媒体源
- [[信源配置表]]：全部信源 + Feed URL + 采集模式（脚本读此表）
- [[媒体信源库]]：信源评分与核查记录

## 使用建议

1. 政策 / 行业源大多可通过 RSSHub 转成 RSS（见 [[RSS 基础设施]]）
2. 用 matcha 或 condenseit 定时生成每日 Markdown 日报（见 [[每日日报聚合工具]]）
3. 日报直接落到本库，重要信息再沉淀进 `2.Areas/` 对应领域
