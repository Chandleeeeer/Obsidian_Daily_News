# 信源配置表

> **本表是采集脚本的数据源**：爆料采集脚本读取「信源类型=爆料源 且 状态=启用」的行来抓取。
> 改表即改采集：新增一行 → 自动纳入；状态改为「🔴 已屏蔽」→ 自动跳过。
> 动态评分由周度核查脚本更新，手动也可改。

## 使用说明

- **固定底座源**：官方/学术，默认 5.0，免检，不参与评分淘汰
- **动态观察池**：行业/财经/时政媒体 + 爆料源，参与评分；评分 < 1.5 自动屏蔽
- 新增信源：复制一行改名称/URL/类型/初始分即可
- Feed URL 为空或非 http 开头的行会被脚本忽略
