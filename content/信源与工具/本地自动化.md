# 每日日报自动化 · 本地部署记录

本库已部署一套本地自动化「每日政策 + 行业日报」流水线。

## 架构

```
信源（RSS / RSSHub / Google News）
  → Matcha（抓取 + 去重 + AI 摘要）
  → Markdown 日报 → 2.Areas/每日日报/
  → Windows 计划任务每天 08:00 自动执行
```

| 组件 | 说明 | 位置 |
| --- | --- | --- |
| Matcha v0.9.0 | 日报生成器（Windows 版） | `D:\Obsidian\_tools\policy-daily\matcha\matcha.exe` |
| RSSHub | 国内政策源 RSS 生成（tsx 运行） | `D:\Obsidian\_tools\policy-daily\rsshub\`（端口 1200） |
| Ollama | 本地 AI 摘要（qwen2.5:7b，GPU） | 系统服务，端口 11434 |
| 计划任务 | 每日 08:00 运行 | `PolicyDaily-Daily` / `PolicyDaily-RSSHub` |

## 已确认可用的 RSSHub 政策路由

| 路由 | 说明 |
| --- | --- |
| `/gov/miit/zcjd` | 工信部政策解读 |
| `/gov/miit/zcwj` | 工信部政策文件 |
| `/gov/ndrc/xwdt` | 发改委新闻动态 |
| `/gov/ndrc/zfxxgk` | 发改委信息公开 |
| `/gov/pbc/zcyj` | 央行政策研究 |

> 注意：gov.cn 主站（`/gov/zhengce/*`）因站点改版，旧路由已失效（503 空内容），勿用。

## 常用操作

- 立即生成日报：运行 `run_daily.ps1`
- 查看日志：`D:\Obsidian\_tools\policy-daily\logs\`
- 修改信源：编辑 `config.yaml` 中 `feeds` / `summary_feeds` / `google_news_keywords`
- 重启 RSSHub：运行 `start_rsshub.ps1`

## 🌐 网站发布（GitHub Pages + Quartz）· 2026-08-31

把每日情报发布成公开网页，供他人随时查看（长期持续更新）。

### 站点信息

| 项 | 值 |
| --- | --- |
| 站点 URL | https://chandleeeeer.github.io/Obsidian_Daily_News/ |
| GitHub 仓库 | https://github.com/Chandleeeeer/Obsidian_Daily_News（**公开**） |
| 技术栈 | Quartz v4.5.2 + GitHub Pages（免费） |
| 本地项目目录 | `D:\Obsidian\_tools\policy-daily\web\` |
| 内容同步脚本 | `D:\Obsidian\_tools\policy-daily\sync_web.ps1` |
| 部署工作流 | `web\.github\workflows\deploy.yaml` |

### 发布流程（每日自动）

```
每日 08:00 run_daily.ps1 最后一步：
  sync_web.ps1（复制 Vault 内容 → web/content/）
  → git add / commit / push 到 GitHub
  → GitHub Action 自动 npm ci + npx quartz build
  → actions/deploy-pages 发布 → 站点更新
```

### 发布内容范围（重要：隐私边界）

会发布到公开网页的目录：

- `2.Areas/每日日报/`（日报、解读、宏观指标跟踪表、今日速览）
- `2.Areas/情报核查/`（爆料）
- `3.Resources/信源与工具/`（信源清单、配置表、媒体信源库等）
- 根目录：`欢迎.md`、`_PARA使用说明.md`、设计文档

**不会发布**：`.obsidian/`、`_模板/`、`1.Projects/`、`4.Archives/`、`99.assets/`、`.canvas` 文件

> ⚠️ 仓库公开，**私人笔记不要放进上述会发布的目录**。

### 维护手册

| 操作 | 方法 |
| --- | --- |
| 立即更新网站内容 | 运行 `sync_web.ps1`，然后 `cd web` 执行 `git add -A && git commit -m "update" && git push`（或直接跑 `run_daily.ps1` 全流程） |
| 手动触发重新部署（内容无变化时） | `cd web` 执行 `git commit --allow-empty -m "trigger deploy" && git push` |
| 查看部署状态 | 仓库 Actions 页，或 `curl https://api.github.com/repos/Chandleeeeer/Obsidian_Daily_News/actions/runs` |
| 一次性设置（已完成） | 仓库 Settings → Pages → Source: **GitHub Actions** |

### 已知问题 / 注意事项

1. **CustomOgImages 已禁用**：Quartz 社交预览图插件遇不支持的 emoji 会构建崩溃，已在 `web/quartz.config.ts` 注释掉，勿重新启用
2. **dependabot 自动 PR**（依赖更新 31 项）无害，忽略；若以后自动合并后构建失败，先检查 `web/quartz.config.ts`
3. **Pages API 返回 404** 是 GitHub 接口显示问题，站点实际访问正常
4. 首次推送创建分支时不触发 workflow（GitHub 规则），需空提交再触发——已处理
5. git 认证走 Windows 凭据管理器，全局身份 `zhencheng.li`；若推送要求认证，重新登录凭据管理器即可
