# 政策监控工具

GitHub 上可用于「每日整理最新政策」的开源工具。

## 国内政策

| 工具 | 链接 | 说明 |
| --- | --- | --- |
| EcoPolicy-AI | https://github.com/BoussinesqJ/EcoPolicy-AI | 经济政策智能分析引擎：50+ 数据源（国务院 API、各部委）+ 31 省级区域，定时抓取、版本追踪、AI 解读，支持 REST / MCP / 调度 |
| 新闻联播政策信号 | https://github.com/cezum/china-signal-xinwenliaobo | 把新闻联播当政策信号频道，分析报道顺序与措辞变化，识别政策风向 |
| YouthPolicyAlert | https://github.com/niumage1hao/YouthPolicyAlert | 定时抓取城市住建局 / 人社局公告，政策变动自动提醒（架构可改造） |
