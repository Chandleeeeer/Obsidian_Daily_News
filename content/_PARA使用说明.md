# PARA 使用说明

> 本知识库按 **PARA**（Projects / Areas / Resources / Archives）方法组织，用于「政策 + 行业信息」的收集、跟踪与解读。
> PARA 的核心思想：按「行动目标」而不是「内容主题」来分类 —— 同一篇政策，处在不同阶段就放在不同位置。

## 四大分类

| 文件夹 | 英文 | 放什么 | 示例 |
| --- | --- | --- | --- |
| `1.Projects/` | Projects | 有明确目标和截止日期的项目，做完即归档 | 「2026-09 半导体出口管制解读」 |
| `2.Areas/` | Areas | 需要长期维护、持续跟踪的领域，没有终点 | 国内政策、国际政策、行业动态 |
| `3.Resources/` | Resources | 按主题积累的资料库，当前不急于行动 | 政策原文、报告、信源清单 |
| `4.Archives/` | Archives | 已完成或不再活跃的内容 | 已完结项目的产出、过期资料 |

## 工作流：收集 → 跟踪 → 解读 → 归档

1. **捕获**：新看到的信息先落 `3.Resources/`（原文、链接、截图，先存下来再说）
2. **跟踪**：属于长期关注主题的内容，沉淀到 `2.Areas/` 对应领域
3. **立项**：需要产出明确结论或报告的，在 `1.Projects/` 建 `YYYY-MM-主题/` 子文件夹
4. **归档**：项目结束后，把整个项目文件夹移入 `4.Archives/YYYY/`

## 命名与规范

- 笔记命名：`YYYY-MM-DD 主题 类型.md`，如 `2026-08-28 工信部XX政策解读.md`
- 每条政策记录建议包含：政策原文链接、发布机构、发布日期、核心要点、影响分析
- 首次出现的新概念，单独建笔记并用 `[[双向链接]]` 关联
- 归档只移入、不删除，保留完整历史
