# 每日日报 · 说明

本目录由**本地自动化流水线**每天自动生成，无需手动操作。

## 自动化信息

- 生成时间：每天 **08:00**（Windows 计划任务 `PolicyDaily-Daily`）
- 生成工具：Matcha + 本地 RSSHub + Ollama（qwen2.5:7b，RTX 4060 GPU）
- 输出文件：`每日政策日报-YYYY-MM-DD.md`
- 工具目录：`D:\Obsidian\_tools\policy-daily\`
- 日志目录：`D:\Obsidian\_tools\policy-daily\logs\`

## 信源（详见 [[3.Resources/信源与工具/_index|信源与工具索引]]）

- 国内政策：工信部政策解读/政策文件、发改委新闻/信息公开、央行政策研究（经本地 RSSHub）
- 国际政策：美国联邦公报（Federal Register）
- 行业动态：EE Times、SemiEngineering、IEEE Spectrum、Hacker News、TechCrunch、arXiv CV
- Google News 关键词：半导体出口管制 / 工信部政策 / AI Act / image sensor / 自动驾驶法规 / camera ISP

## 手动运行

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\Obsidian\_tools\policy-daily\run_daily.ps1
```

或仅生成（不启动服务）：

```powershell
D:\Obsidian\_tools\policy-daily\matcha\matcha.exe -c D:\Obsidian\_tools\policy-daily\config.yaml
```

## 注意事项

- RSSHub 依赖网络访问 gov.cn / miit.gov.cn 等站点，个别源可能临时失败，属正常现象
- AI 摘要在本地生成，不消耗 API 费用；质量取决于原文页面结构
- 重要信息请手动沉淀到 `2.Areas/` 对应领域或 `1.Projects/` 立项

## AI 解读（每日自动生成）

每天生成日报后，还会自动生成一份 **`解读-YYYY-MM-DD.md`**（Camera 工程师视角）：

- 从政策/行业信源中提取当日新闻 → 本地 AI（qwen3:8b）逐条解读
- 输出：产业链环节 / 背后意图 / 对 camera 影像链路的影响 / 对工程师的意义
- 并给出「今日最重要 3 条」
- 解读方法见解读笔记末尾的「五问框架」



## 解读结构（五段式宏观日报）

`解读-YYYY-MM-DD.md` 按以下五段组织：

1. **宏观数据速览**：国家统计局/央行/财政部发布的数据（M2、社融、CPI、PPI、PMI、就业、工业利润、固投、地产、社零、进出口等），带数值与解读
2. **国内政策与宏观环境**：政策要点 + 意图 + 小结
3. **国际局势与美联储/全球流动性**：地缘政治 + 全球央行/市场 + 小结
4. **产业趋势**：半导体/AI/汽车/机器人/影像 + 小结
5. **与 Camera 工程师的关联**：上面四块对影像调试工作的意义

> 数据类条目自动从统计局/央行/财政部等信源抓取，官方发布 M2/CPI/PMI 等指标时会自动收录。
